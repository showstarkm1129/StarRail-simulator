# 崩壊スターレイル シミュレーター (StarRail-simulator)

崩壊スターレイル (Honkai: Star Rail) のキャラクタービルド、火力、および行動順（速度）を計算・検証するためのWebベースのシミュレーターです。
HTML、CSS、Vanilla JavaScript (ES Modules) で構成されており、ビルドツールを必要とせずブラウザ上で直接動作します。

## フォルダ・ファイル構成

### 全体ツリー図

プロジェクトの全体構造は以下のようになっています。

```text
StarRail-simulator/
├── index.html           # アプリケーションのエントリーポイント
├── Timer_plus_icon.png  # アプリ用アイコン画像
├── CLAUDE.md            # 開発用ドキュメント
├── README.md            # 本ファイル（プロジェクト構成）
├── css/                 # スタイルシート
│   └── style.css
└── js/                  # アプリケーションロジック
    ├── bootstrap.js     # ES Modulesエントリーポイント
    ├── simulator.js     # 「戦闘シミュ」タブ用スクリプト
    ├── speed.js         # 「速度・行動回数」タブ用スクリプト
    ├── ui.js            # 共通UI処理スクリプト
    ├── build/           # 計算・システム中核層 (ステータス計算など)
    ├── data/            # データ定義層 (キャラ、装備データ)
    │   ├── characters/
    │   ├── lightcones/
    │   ├── Cavern Relics/
    │   └── Planar Ornaments/
    └── ui/              # UIコンポーネント層 (複雑なUI処理)
```

---

### ルートディレクトリ

| ファイル・フォルダ名 | 解説 |
| :--- | :--- |
| `index.html` | アプリケーションのエントリーポイントとなるHTMLファイルです。「速度・行動回数」「戦闘シミュ」「限界効用逓減」の3つのタブで構成されています。 |
| `css/` | スタイルシートを格納するフォルダです。 |
| ├── `style.css` | アプリケーション全体のUIデザインを定義するCSSファイルです。 |
| `Timer_plus_icon.png` | アプリ内で使用されるアイコン画像です。 |
| `CLAUDE.md` | 開発者向けの内部ドキュメント・コーディング規約が記載されたファイルです。 |
| `js/` | アプリケーションのロジックを担うJavaScriptファイルを格納するフォルダです。 |

---

### `js/` ディレクトリ（ルート直下）
各機能のエントリーポイントとなるスクリプトが配置されています。

| ファイル名 | 解説 |
| :--- | :--- |
| `bootstrap.js` | ES Modulesのエントリーポイントです。データ層を読み込み、計算モジュールをグローバル (`window.SRSIM`) に公開して他のスクリプトから利用できるようにします。 |
| `simulator.js` | 「戦闘シミュ」タブのロジックを担当するファイルです。 |
| `speed.js` | 「速度・行動回数」タブのロジック（行動値・ラウンド計算など）を担当するファイルです。 |
| `ui.js` | 複数のタブで共通して使用されるDOM（画面要素）操作を担うファイルです。 |

---

### `js/build/` ディレクトリ（計算・システム中核層）
ステータス計算、ビルド管理、シミュレーションのコアロジックが配置されています。

| ファイル名 | 解説 |
| :--- | :--- |
| `registry.js` | キャラクター、光円錐、遺物、オーナメントのデータを一元管理する登録庫（レジストリ）です。 |
| `constants.js` | 属性、運命、装備スロットなどのシステム全体で使う定数（列挙型）を定義しています。 |
| `statKeys.js` | ステータスのキー（攻撃力、HP、会心率など）を定数として定義しています。タイポを防ぐために重要なファイルです。 |
| `statComputer.js` | キャラクターの基礎ステータスと装備から、最終的な実ステータスを算出する計算エンジンです。 |
| `diminishing.js` | 「限界効用逓減」タブのコアロジックです。ステータス変化による火力への貢献度を計算します。 |
| `buildStore.js` | 作成したキャラクタービルドをブラウザのLocalStorageに保存・読み込みするためのファイルです。 |
| `buildToEntity.js` | 保存されたビルドデータを、戦闘シミュレーターで扱えるキャラクターエンティティ形式に変換します。 |
| `relicMainTable.js` | 遺物のメインステータスのマッピングデータを定義しています。 |
| `substatTable.js` / `substatRoller.js` | 遺物のサブステータスの抽選テーブルと、そのロール（強化）処理のロジックです。 |
| `skillUtil.js` | スキルの種別判定など、戦闘計算で使われる共通のユーティリティ関数群です。 |

---

### `js/data/` ディレクトリ（データ定義層）
ゲーム内のキャラクターや装備などの各種データが定義されています。

| フォルダ名 | 解説 |
| :--- | :--- |
| `characters/` | キャラクターの基本ステータスやスキルの定義ファイルが格納されています。 |
| `lightcones/` | 光円錐のステータスやパッシブ効果の定義ファイルが格納されています。 |
| `Cavern Relics/` | トンネル遺物（4部位セット）のセット効果の定義ファイルが格納されています。 |
| `Planar Ornaments/` | 次元界オーナメント（2部位セット）のセット効果の定義ファイルが格納されています。 |

※ 各フォルダ内のデータは `_index.js` で集約され、自動的にシステム（Registry）に登録される仕組みになっています。

---

### `js/ui/` ディレクトリ（UIコンポーネント層）
特定のタブや機能に特化したUI関連のロジックが配置されています。

| ファイル名 | 解説 |
| :--- | :--- |
| `diminishingUI.js` | 「限界効用逓減」タブにおける、比較表の生成やパーティバフの管理など、複雑なUI処理を担当しています。 |
