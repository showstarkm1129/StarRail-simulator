# 遺物データのメモ

## 属性タグが空のセットについて（2026-08-10）

遺物セットの `tags.attribute` は、属性・攻撃・会心などの火力条件でセットを絞り込むための情報です。
`RELIC_USAGE.OFFENSE` を持たない耐久・サポート用セットには、無関係な火力タグを付けないため `attribute: []` を正しい値として残します。

この種類のセットでは `RELIC_ATTRIBUTE` を参照しないため、constants からの import に含めません。未使用 import の警告を消すことが目的ですが、タグを削除・推測して火力用に分類し直す変更ではありません。
