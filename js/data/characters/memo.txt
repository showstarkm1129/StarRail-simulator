キャラクター一括登録メモ
========================

今回の方針
----------
- ver4.3までの生成キャラクター77件について、崩壊スターレイル日本語Wikiの各キャラページから「軌跡」表を取得し、各キャラファイルに通常攻撃 / 戦闘スキル / 必殺技 / 天賦 / 秘技などを登録。
- 各キャラクター自身の `.js` ファイルに、基礎値 / 軌跡ステータス / スキル倍率 / 追加能力 / 星魂説明を直接登録している。
- `_defineCharacter.js` は、各ファイルに書かれたデータを既存キャラ定義の `skills` / `extras` / `eidolonsDetail` と同じ形に整形するための共通ヘルパー。
- 既に個別実装済みのキャラは上書きしていない。

補完・未確定
------------
- Wiki上で Lv.11 などが `%` 表記のものは、前後Lvの値が取れる場合に線形補完した。
- 補完した項目と、Wiki上で明確に値が空欄のまま残った項目は、各キャラファイル内の `inferredNotes` と `null` 値として残している。
- 未確定値は `null` のまま保持している。検証では通るが、該当キャラを厳密に詰める時は個別ページの更新確認が必要。

今後の改善候補
--------------
- 自動抽出では表の列名から `atk` / `hpPct` / `healPct` などを推定しているため、複雑な複合効果は `value1` などの汎用キーで保持される場合がある。
- 条件付きバフや敵デバフの `partyEffects` / `enemyEffects` 化は、各キャラの個別実装で精査する。


partyEffects / enemyEffects / selfEffects 実装メモ
================================

実装方針
--------
- Wiki本文から対象が明確な味方バフ、敵デバフ、自己バフ/自己デバフを各キャラクターファイルへ追加。
- 敵の防御力ダウン / 耐性ダウン / 被ダメージアップ / 防御無視は、現状の火力計算でも効くよう partyEffects にもミラー。
- 支援者/本人の攻撃力・HP・速度・会心ダメージ・撃破特効・効果命中などに比例する効果は共通ヘルパーで計算する形にした。
- 特定属性の被ダメージアップは、全被ダメージではなく属性ダメージ枠で扱う。

現在の登録件数
------------
- 対象ファイル: 77 (生成キャラのみ。既存の個別実装キャラは除外)
- partyEffects: 148
- enemyEffects: 51
- selfEffects: 210

追加した共通枠
------------
- 攻撃種類ごとの会心率 / 会心ダメージを追加。
  - CRIT_RATE_BASIC / SKILL / ULT / FOLLOWUP
  - CRIT_DMG_BASIC / SKILL / ULT / FOLLOWUP
- 攻撃種類ごとの防御無視 / 耐性貫通 / 被ダメージアップを追加。
  - DEF_IGNORE_BASIC / SKILL / ULT / FOLLOWUP
  - RES_PEN_BASIC / SKILL / ULT / FOLLOWUP
  - DMG_TAKEN_BASIC / SKILL / ULT / FOLLOWUP
- これにより、ロビン昇格4、トパーズE1、ケリュドラ戦闘スキル、椒丘必殺技のような「特定攻撃だけ効く」効果を全攻撃へ過大適用せず登録できるようにした。

未実装・保留
------------
- 超撃破、愉悦度、弱点撃破効率、行動順操作、SP/EP回復、治癒、バリア、味方の被ダメージ軽減は、現在の火力比較では正確に扱えないため未登録またはメモ止め。
- 持続被ダメージ / 持続ダメージ専用の補正は、全ダメージ被ダメージアップとして入れると過大評価になるため未登録。
  代表例: サンポ必殺技、カフカE1/E2、ブラックスワン「アルカナ」の防御無視。
- 記憶の精霊・召喚物だけの速度やステータスは、装備者と別個のステータス枠がまだ無いため一部のみ近似。
  代表例: アグライア昇格2のラフトラ速度分、景元「神君」の速度/段数。
- ロビンE6の物理付加ダメージ会心ダメージ+450%は、味方本体の攻撃ではなくロビン固有の付加ダメージ専用のため未登録。
- 条件がゲーム内状態に強く依存するものは defaultActive:false / target:single / stackable などで手動切替前提にした。

Ver.4.4 追加（2026-08-06）
------------------------
- 実装済みのVer.4.3（千冶・刃、不死途）を確認したうえで、Ver.4.4の以下3名を追加。
  - 姫子・旅立ち（Himeko • Nova）: 知恵・炎
  - ギルガメッシュ: 壊滅・雷
  - 遠坂凛（Rin Tohsaka）: 知恵・量子
- 各ファイルにLv.80基礎ステータス、軌跡ステータス、スキル倍率、主要な自己/味方/敵バフ、星魂説明、参照Wiki URLを登録。
- これにより、キャラクターはVer.4.4まで追加済み（実キャラクター数90名）。

Ver.4.4で未確定・未変換の項目
------------------------------
- 日本語Wikiで空欄のLv.11・Lv.12倍率は補完せず null として保持。将来、公式値が掲載された時点で差し替える。
- 姫子・旅立ちの支援スキル専用ダメージ、召喚中の行動順・回数・EP回復などは、現行の火力比較用ステータス枠がないため、数値説明と倍率テーブルのみ登録。
- ギルガメッシュの味方最大EPに応じた可変バフ、遠坂凛のSP/宝石エネルギー消費に伴う攻撃回数は、対象ごとの戦闘状態を持たないため手動ON/OFFまたは未変換で扱う。
